# 📚 Nexus Core: Advanced Library Management System

An ultra-modern, high-fidelity Library Management Portal built using the MERN stack (MongoDB, Express, React, Node.js). Featuring a futuristic dark cyberpunk-inspired dashboard aesthetic with automated identity provisioning, live ledger transaction tracking, and decentralized workspace viewports.

---

## 🚀 Key Functional Systems

- **Administrative Core Terminal:** Secure cryptographic login barrier (`admin@library.com` // `admin123`) utilizing JWT allocation controls.
- **Glassmorphic Interactive Metrics:** Live system overview counters displaying volume metrics, active subscription populations, and response delay calculations.
- **Dynamic Asset Ingestion Engine:** Seamless metadata indexing for book catalogs with automated ISBN record mapping.
- **Identity Authentication Control Matrix:** Autonomous background token generator (`MEM-XXXX`) for managing member profiles.
- **Lending Dispatch Archive Ledger:** Integrated borrow-and-return system connecting relational book datasets directly to active membership rosters.

---

## 🛠️ Architecture & Core Dependencies

### Backend Ecosystem
- **Runtime Environment:** Node.js (v24.17.0+)
- **Application Framework:** Express.js
- **Network Interface:** Cross-Origin Resource Sharing (CORS Enabled)
- **Token Cryptography:** JSON Web Tokens (jsonwebtoken)

### Frontend Framework
- **Build Engine & Bundler:** Vite (v5/v8 Environment Core)
- **Component Architecture:** React 18+ (Declarative Viewports Engine)
- **Styling Architecture:** Tailwind CSS v4 Hybrid Processing
- **Asynchronous Data Client:** Axios Interceptor Instance Tracker
- **Feedback Notifications:** React Hot Toast Dispatch System

## 🏃‍♂️ Microservice Initialization & Launch Pipeline

To initialize and deploy this management network locally on your server node, execute the following operational pipelines inside two distinct split terminals:

### 1. Launching the Backend Database Cluster
Open your terminal environment, step down into the server microservice folder, install dependencies, and spin up the Nodemon listener layer:
```bash
cd backend
npm install
npm run dev
```
*The endpoint port will initialize and lock on `http://localhost:5000`.*

### 2. Initializing the User Interface Workspace
Open your second terminal, step into your client interface module, install packages, and deploy the Vite hot-reloading asset bundle server:
```bash
cd frontend
npm install
npm run dev
```
*The terminal viewport compiler will complete and provision a secure local view on `http://localhost:3000`.*
